견적 산출

단가는 원화(KRW)가 기준이며 USD는 환율로 자동 환산됩니다. 오른쪽 환율 칸에서 값을 바꾸거나 환율 갱신을 누르면 전 품목 USD가 즉시 다시 계산됩니다(웹 서버에 올리면 매일 자동 갱신). 단가·박스입수가 확보된 품목은 미리 채워져 있어 주문 박스수만 넣으면 됩니다. 주황색 박스입수 칸은 아직 값이 없어 금액이 계산되지 않는 품목입니다.
CTN/PLT는 박스 치수·중량과 팔레트 규격으로 자동 산출한 이론 적재수이며, 적재율은 부피와 중량 중 먼저 차는 쪽을 기준으로 표시합니다. 박스 kg 옆의 *는 원본 오류를 보정했거나 낱개×입수로 추정한 값입니다.
박스 규격(L×W×H)과 박스 kg은 표에서 바로 입력할 수 있습니다. 값을 넣으면 CBM·CTN/PLT·적재율이 즉시 다시 계산되고 해당 품목은 수정됨으로 표시됩니다.
MOQ보다 적게 주문하면 주문 CTN 칸이 주황색으로 바뀌고, 하단에 미달 건수가 집계됩니다. 주문 PLT에 팔레트 수를 넣으면 주문 CTN이 자동으로 채워집니다. 입력값은 이 화면에만 남습니다 — 엑셀 다운로드로 저장하고, 다음에 엑셀 업로드로 이어서 작업하세요. 양식은 통합 워크북의 「14_견적입력_양식」 시트와 동일합니다.
